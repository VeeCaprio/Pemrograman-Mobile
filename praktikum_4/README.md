# Praktikum 4 — Pemrograman Mobile

## 1. Deskripsi Praktikum

Praktikum 4 merupakan kegiatan pembelajaran Pemrograman Mobile menggunakan Flutter dan bahasa pemrograman Dart. Pada praktikum ini, mahasiswa mempelajari pengembangan aplikasi mobile dengan menyusun kode program ke dalam struktur yang lebih terorganisasi serta memahami penggunaan class dan objek dalam aplikasi.

Melalui praktikum ini, mahasiswa diharapkan mampu memahami dasar pengembangan antarmuka aplikasi Flutter, pengelolaan data, serta proses menjalankan dan menguji aplikasi pada emulator Android.

## 2. Tujuan Praktikum

Tujuan dari Praktikum 4 adalah:

1. Memahami dasar pengembangan aplikasi mobile menggunakan Flutter.
2. Memahami penggunaan bahasa pemrograman Dart dalam aplikasi.
3. Memahami konsep class dan objek untuk merepresentasikan data.
4. Memahami cara menyusun kode program agar mudah dibaca dan dikelola.
5. Menjalankan aplikasi Flutter menggunakan emulator Android.
6. Melakukan pemeriksaan dan perbaikan kesalahan pada kode program.

## 3. Teknologi yang Digunakan

* **Flutter** — framework untuk mengembangkan aplikasi mobile.
* **Dart** — bahasa pemrograman yang digunakan dalam Flutter.
* **Android Emulator** — digunakan untuk menjalankan dan menguji aplikasi.
* **Visual Studio Code / Android Studio** — digunakan untuk mengedit dan mengelola kode program.
* **Terminal** — digunakan untuk menjalankan perintah Flutter.

## 4. Konsep yang Dipelajari

### A. Struktur Program Flutter

Aplikasi Flutter memiliki fungsi utama `main()` sebagai titik awal eksekusi program. Fungsi `runApp()` digunakan untuk menjalankan widget utama aplikasi.

### B. Widget

Widget merupakan komponen dasar untuk membangun antarmuka aplikasi Flutter. Widget digunakan untuk menampilkan teks, tombol, tata letak, serta elemen antarmuka lainnya.

### C. Class dan Objek

Class digunakan sebagai cetak biru untuk membentuk objek. Dalam aplikasi, class dapat digunakan untuk merepresentasikan data dengan atribut dan perilaku tertentu.

### D. Pengelolaan Data

Data aplikasi perlu disusun dan dikelola dengan baik agar dapat digunakan untuk menampilkan informasi pada antarmuka. Pemisahan model data dari tampilan juga membantu menjaga keteraturan kode.

### E. Pengujian Aplikasi

Aplikasi perlu dijalankan melalui emulator untuk memastikan program dapat dikompilasi dan menampilkan antarmuka sesuai dengan implementasi kode.

## 5. Langkah Menjalankan Aplikasi

Pastikan Flutter sudah terpasang dan emulator Android tersedia.

1. Buka Terminal.

2. Masuk ke direktori proyek Praktikum 4:

   ```bash
   cd praktikum_4
   ```

3. Unduh dependensi yang dibutuhkan:

   ```bash
   flutter pub get
   ```

4. Periksa kode program:

   ```bash
   flutter analyze
   ```

5. Jalankan aplikasi:

   ```bash
   flutter run
   ```

6. Amati tampilan aplikasi pada emulator Android dan pastikan tidak terdapat kesalahan saat aplikasi dijalankan.

## 6. Hasil Praktikum

Hasil praktikum berupa proyek aplikasi Flutter yang dapat dijalankan pada emulator Android. Melalui pengerjaan praktikum, mahasiswa mempelajari struktur kode Flutter, penggunaan Dart, pengelolaan data, serta proses pemeriksaan dan perbaikan kesalahan program.

Dokumentasi hasil dapat dilengkapi dengan screenshot kode program dan tampilan aplikasi ketika dijalankan pada emulator.

## 7. Kesimpulan

Praktikum 4 membantu mahasiswa memahami dasar pengembangan aplikasi mobile menggunakan Flutter dan Dart. Mahasiswa mempelajari struktur program, penggunaan widget, konsep class dan objek, serta proses menjalankan dan memeriksa aplikasi. Materi ini menjadi dasar untuk mengembangkan aplikasi mobile yang lebih kompleks pada praktikum berikutnya.
